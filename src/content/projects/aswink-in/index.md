Built from scratch with Astro's Content Layer API, a hand-tuned dotted-grid design system, and a manual light/dark theme toggle. Blog posts and project entries are both Markdown-based content collections; screenshots use `astro:assets` for on-the-fly image optimization. Hosted on Vercel, with Cloudflare Web Analytics for cookie-free page view tracking.
